# projet-python
Ensemble des fichier du projet du cours de méthodes numériques


L'ajout de fichiers ce fait avec le bouton "add file" en haut à gauche si le fichier ajouté à le même nom qu'un fichier existant cela ajoutera la nouvelle version sur la page et l'ancienne version du fichier sera supprimée. Ne pas oublier de cliquer sur "commit changes"pour confirmer l'ajout des nouveaux fichiers !
